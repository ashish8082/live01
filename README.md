# IPTV Streaming App

A modern IPTV streaming application built with React.js that allows users to browse channels and movies and play live HLS (`.m3u8`) streams directly in the browser.

## 🚀 Technologies Used

- React.js
- React Router DOM
- Tailwind CSS
- HLS.js
- JavaScript
- HTML5 Video
- IPTV M3U / M3U8
- Node.js / Express.js (Backend, if applicable)
- MongoDB (if applicable)

## ✨ Features

- 📺 Live IPTV channel streaming
- 🎬 Movies section
- 🔥 HLS `.m3u8` video playback
- 📋 IPTV M3U playlist support
- 🔎 Channel search
- 📱 Responsive design
- 🔐 Login popup
- 🧭 React Router navigation
- 📄 About page
- 📞 Contact page
- 🔒 Privacy Policy
- 📜 Terms & Conditions
- ❌ 404 / Page Not Found page
